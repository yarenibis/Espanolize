# 🌍 Espanolize

Espanolize is a modern language-learning platform focused on teaching Spanish grammar, vocabulary, and daily usage in a clear, structured, and user-friendly way.
The platform is designed especially for A1–B1 level learners, combining educational content with a scalable, production-ready architecture.
Web-site link :[(www.espanolize.com)]

## 🚀 Features

📚 Structured Grammar Topics

Themes → Topics → Grammar Rules → Examples

📝 A1–B1 Level Content

Clear explanations with real-life examples

🌐 SEO-Friendly Content Structure

Optimized titles, descriptions, and semantic organization

🏥 Vocabulary Modules

Hospital terms, daily routines, pronouns, and more

🔐 JWT-Based Authentication
